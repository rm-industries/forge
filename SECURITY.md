# Security Policy

## Supported versions

Forge is pre-release software. Security fixes are applied to the latest code on
the default branch and included in the next available release. Older pre-release
versions are not maintained with separate security backports.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull
request. Report it privately through
[GitHub private vulnerability reporting](https://github.com/rm-industries/forge/security/advisories/new).

Include the affected version or commit, reproduction steps, potential impact,
and any suggested mitigation. A maintainer will acknowledge the report and
coordinate validation, remediation, and disclosure through the private advisory.
Please allow maintainers time to investigate before publishing details.
