A useful starter should make the first page feel considered without deciding
what every future page must become.

Begin with a clear hierarchy, dependable spacing, and components that can be
replaced one at a time. The result is easier to understand and safer to
customize.

## Start with the essentials

1. Establish a readable hierarchy.
2. Keep the first set of components small.
3. Replace examples as the site's purpose becomes clearer.
